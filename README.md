# 神學研究網站

獨立的靜態網站。從 index.html 進入每日經課深度研究；explore.html 提供神學觀點比較與歷史時空探索。

發佈：建立獨立 GitHub repository，將此資料夾內容放到發佈分支根目錄，在 Pages 設定選取該分支與根目錄。頁面亦可在其他靜態主機發佈。以 HTTPS 開啟，讓瀏覽器可以讀取同一網站的 daily.json。

每日更新：保留 daily.json 的欄位結構，以當天香港日期的完整稿件更新此檔。發佈完成後，查閱公開網站回傳的 daily.json，確認日期與標題。請在新網站及寫入權限驗證後再切換香港時間 08:00 的排程。

# 神學研究網站

獨立的靜態網站。從 index.html 進入每日經課深度研究；explore.html 提供神學觀點比較與歷史時空探索。

發佈：[公開網站](https://cingaryee-bible.github.io/-theology-study/) 由 GitHub Pages 從 `main` 分支根目錄發佈。瀏覽器從同一網址載入 `daily.json`。

每日更新：保留 daily.json 的欄位結構，以當天香港日期的完整稿件更新此檔。發佈完成後，查閱公開網站回傳的 daily.json，確認日期與標題。每日更新排程使用香港時間 08:00。

以弗所劇場照片的署名及 CC BY-SA 3.0 授權連結載於 explore.html。
